# AI-Quota v0.1.0-beta.1

首个可直接下载的公开测试版。2026-10-14。

## 下载与安装

- **DMG**：`AI-Quota-0.1.0-beta.1-universal.dmg`，打开后拖入 Applications。
- **ZIP**：`AI-Quota-0.1.0-beta.1-universal.zip`，备用直接解压应用包。
- **SHA256SUMS**：下载完整性校验。

[下载测试版](https://github.com/Win1leven/AI-Quota/releases/tag/v0.1.0-beta.1) · [中文使用说明](../USAGE.zh-CN.md)

macOS 13+，Universal（Apple Silicon + Intel）。安装应用不需要编译工具。Codex 额度需要已登录的 Codex CLI；Claude 可选择已登录桌面端的 opt-in 读取，或活动时采样的 Code 采集器（后者需要 python3）。

**签名边界**：ad-hoc 临时签名，未 Developer ID 分发签名、未 Apple 公证。首次打开可能被系统拦截；确认来源与完整性后，先尝试打开，再在“系统设置 → 隐私与安全性 → 仍要打开”允许该应用。不要关闭系统整体门禁。

## 包含功能

- Codex/Claude 配额窗口、已知剩余额度、账户返回的重置时间。
- 明确采样时间与 Cached/Stale，失败保留有效缓存，不推算重置日期。
- Claude 桌面端可独立提供配额及重置时间，登录访问默认关闭、需手动启用。
- 可逆的 Claude Code 状态栏采集，保留原显示命令。
- 菜单栏、桌面双服务胶囊、详情浮窗与设置；胶囊支持拖动、刷新和右键菜单。
- 新应用图标、中文安装/使用/排查/卸载指南。
- 修复版本显示与隐私说明；移除历史 Claude Code 凭据自动探测/Anthropic 网络统计，只保留本地统计。

## 本次验证

- 最新源码 52 个合成测试、8 个套件全部通过。
- arm64/x86_64 release 编译成功，Mach-O 最低系统为 13.0；动态依赖为系统库，图标和版本元数据正确。
- 代码签名严格验证通过；ZIP 与 app 文件逐字节一致。
- DMG 完整性校验、只读挂载、Applications 链接、中文指南和临时目录复制安装通过；复制后的 app 签名仍有效。
- 临时独立 Bundle ID + 临时用户目录，禁止网络和真实用户目录访问，Apple Silicon 完成原生启动（isFinishedLaunching=true），8 秒后仍正常运行；未修改已安装应用或真实账户配置。
- 独立代码/发布差异审查无未处理 P1/P2。既有真实桌面端配额与 UI 验收见项目进度。

本次隔离启动验证不等于完整交互验收或真实账户 API 验收。**Intel 和 macOS 13 最低版本未在真机运行；真实重置边界仍未观察。** Claude 私有 usage 接口和 Cookie 格式、第三方 CLI 更新可能影响兼容性。无自动更新/开机启动。UI 目前主要为英文。

本地额度与统计落盘；本地 token 统计会读会话文件 usage 字段，聊天内容不上传。Codex 使用已有登录请求提供方；Claude 桌面访问显式 opt-in，仅向 claude.ai usage 发送必要会话 Cookie，凭据不持久化。反馈前检查诊断中的个人额度与时间，勿上传凭据或原始会话。
